## Сводка по артефактам сборки

| Сборка | Артефакт | Размер | R8 / Shrink | Подпись | Примечание |
|---|---|---|:---:|---|---|
| **Debug** | `app-debug.apk` | 63 МБ | Выкл | Debug Key | Для активной разработки |
| **Staging** | `app-staging.apk` | 30 МБ | Вкл (`debuggable=true`) | Debug Key | Для диагностики R8 с логами и маппингом |
| **Release** | `app-release.apk` | **10 МБ** | Вкл (`debuggable=false`) | Release Key (RSA-2048, v2) | Чистый релизный APK для установки |
| **Release Bundle** | `app-release.aab` | **8.3 МБ** | Вкл | Release Key (RSA-2048, v2) | Готов к загрузке в Google Play |
| **Server** | `timecapsule-server.jar` | **25 МБ** | N/A (Fat JAR) | N/A | Автономный запуск через `java -jar` |
